RDAI - Stock app for RDK
========================

START:  double-click RDAI.exe
        A black window opens and the app opens in your browser by itself.
        Keep the black window open while you work. Close it to stop RDAI.

YOUR DATA:  the folder "data" next to RDAI.exe (file rdai.db).
            Copy that file to a pen drive or Google Drive every day.

UPDATING TO A NEW VERSION:  extract the new zip, then copy your old "data" folder
            into the new RDAI folder (replace when asked).

ASSISTANT (Ask RDAI page):  needs internet and a Claude API key
            (console.anthropic.com -> API Keys). Paste it once on the Settings page.
            Everything else works without internet.

If Windows shows "Windows protected your PC": click "More info" -> "Run anyway".
